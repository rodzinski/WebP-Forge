# Apoio ao projeto

A página `/support` oferece formas gratuitas de apoiar o WebP Forge e direciona contribuições financeiras ao perfil oficial aprovado no GitHub Sponsors.

## Ativar apoio financeiro

O endereço padrão é `https://github.com/sponsors/rodzinski`. Para substituir a plataforma no futuro, defina `NEXT_PUBLIC_SUPPORT_URL` no build do Cloudflare e faça um novo deploy.

Nunca coloque chaves Pix privadas, tokens de API, dados bancários ou credenciais no repositório. A variável deve conter apenas uma URL pública HTTPS.
